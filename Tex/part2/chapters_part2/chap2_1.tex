Hugging Face khởi đầu là một công ty chatbot và nay là trung tâm của cộng đồng NLP mã nguồn mở. Các thư viện của họ được thiết kế để dùng cùng nhau, nhằm đơn giản hóa và chuẩn hóa quy trình làm việc với các mô hình Transformer.

Trước hết cần cài đặt bốn thư viện cốt lõi và hiểu vai trò của từng thư viện.

\subsection{Transformers: tải và huấn luyện mô hình pre-trained}
\label{ssec:hf_transformers}
\textbf{Transformers} cung cấp một giao diện nhất quán để tải về, sử dụng và huấn luyện hàng nghìn mô hình Transformer đã được huấn luyện trước (pre-trained models) từ \textbf{Hugging Face Hub}. Hub là một nền tảng trực tuyến tương tự GitHub, nơi cộng đồng chia sẻ mô hình, bộ dữ liệu và các bản demo; đây là tài nguyên quan trọng nhất trong hệ sinh thái.

Ba thành phần chính của thư viện:
\begin{itemize}
    \item \texttt{pipeline}: API cấp cao cho các tác vụ NLP phổ biến, gọi được trong vài dòng code, phù hợp để thử nghiệm nhanh và tạo demo.
    \item \texttt{AutoModel}, \texttt{AutoTokenizer}: các lớp “tự động”. Bạn cung cấp tên của một mô hình trên Hub (ví dụ \texttt{"bert-base-uncased"}), các lớp này tìm, tải về và khởi tạo đúng kiến trúc mô hình và tokenizer tương ứng.
    \item \texttt{Trainer}: API huấn luyện cấp cao, xử lý các phần việc của vòng lặp huấn luyện (training loop) như tối ưu hóa, lên lịch tốc độ học (learning rate scheduling), đánh giá và lưu trữ mô hình.
\end{itemize}

\begin{example}{Dùng \texttt{pipeline} để phân loại cảm xúc}{ex:hf_pipeline}
    \begin{minted}{python}
    from transformers import pipeline

    # Tải một mô hình đã được fine-tune cho phân tích cảm xúc
    # Lần đầu chạy, pipeline sẽ tự động tải mô hình từ Hub
    classifier = pipeline("sentiment-analysis")

    # Sử dụng mô hình
    result = classifier("Hugging Face is democratizing NLP!")
    print(result)
    # Output: [{'label': 'POSITIVE', 'score': 0.9998...}]
    \end{minted}
\end{example}

\subsection{Datasets: tải và xử lý bộ dữ liệu}
\label{ssec:hf_datasets}
\textbf{Datasets} cung cấp một cách tiêu chuẩn hóa để tải về, xử lý và làm việc với các bộ dữ liệu, kể cả các bộ dữ liệu lớn. Ba tính năng chính:
\begin{itemize}
    \item \textbf{Truy cập hàng nghìn bộ dữ liệu:} Tương tự \texttt{transformers}, thư viện \texttt{datasets} tải về hàng nghìn bộ dữ liệu công khai từ Hugging Face Hub chỉ bằng một dòng lệnh (\texttt{load\_dataset}).
    \item \textbf{Xử lý hiệu quả bộ nhớ (Memory-mapping):} Với các bộ dữ liệu hàng trăm GB, \texttt{datasets} không tải toàn bộ vào RAM mà dùng kỹ thuật memory-mapping (được Apache Arrow hỗ trợ), cho phép truy cập và xử lý dữ liệu ngay trên đĩa cứng.
    \item \textbf{API xử lý:} Các phương thức \texttt{.map()}, \texttt{.filter()}, \texttt{.shuffle()} áp dụng các hàm tiền xử lý (như tokenization) lên toàn bộ bộ dữ liệu một cách song song.
\end{itemize}

\begin{example}{Tải và xử lý một bộ dữ liệu với \texttt{datasets}}{ex:hf_datasets}
    \begin{minted}{python}
    from datasets import load_dataset
    from transformers import AutoTokenizer

    # Tải bộ dữ liệu GLUE, tác vụ MRPC
    raw_datasets = load_dataset("glue", "mrpc")
    # >>> raw_datasets
    # DatasetDict({
    #     train: Dataset({
    #         features: ['sentence1', 'sentence2', 'label', 'idx'],
    #         num_rows: 3668
    #     })
    #     ...
    # })

    # Tải tokenizer tương ứng với một checkpoint
    checkpoint = "bert-base-uncased"
    tokenizer = AutoTokenizer.from_pretrained(checkpoint)

    # Viết một hàm để tokenize dữ liệu
    def tokenize_function(example):
        return tokenizer(example["sentence1"], example["sentence2"], truncation=True)

    # Áp dụng hàm này lên toàn bộ bộ dữ liệu
    # batched=True xử lý nhiều mẫu cùng lúc để tăng tốc
    tokenized_datasets = raw_datasets.map(tokenize_function, batched=True)
    print(tokenized_datasets)
    \end{minted}
\end{example}

\subsection{Accelerate: đơn giản hóa huấn luyện phân tán}
\label{ssec:hf_accelerate}
\textbf{Accelerate} là một lớp trừu tượng (abstraction layer) cho phép chạy cùng một đoạn code huấn luyện trên các môi trường phần cứng khác nhau (một GPU, nhiều GPU, TPU) mà \textbf{không cần thay đổi code}; triết lý của thư viện là “Write your PyTorch code once, run it anywhere.” Thư viện tự xử lý các việc sau:
\begin{itemize}
    \item Đặt các tensor và mô hình lên đúng thiết bị (device placement).
    \item Bao bọc mô hình và optimizer trong các lớp phù hợp cho huấn luyện phân tán, ví dụ \texttt{Distributed\allowbreak Data\allowbreak Parallel}.
    \item Thu thập (gather) các kết quả từ nhiều tiến trình khác nhau.
\end{itemize}
Bạn chỉ cần thêm một vài dòng code \texttt{accelerate} vào đầu kịch bản huấn luyện PyTorch tiêu chuẩn của mình. \texttt{Trainer} của \texttt{transformers} đã tích hợp sẵn \texttt{accelerate} ở bên trong.

\subsection{Evaluate: thư viện tính metric đánh giá}
\label{ssec:hf_evaluate}
\textbf{Evaluate} cung cấp các cách triển khai đáng tin cậy để tính và so sánh các metric đánh giá trong NLP và các lĩnh vực khác. Ba tính năng chính:
\begin{itemize}
    \item \textbf{Thư viện metric lớn:} Các cách triển khai đã được kiểm chứng cho hàng chục metric phổ biến (BLEU, ROUGE, F1, Accuracy, Perplexity, ...).
    \item \textbf{Giao diện đơn giản:} \texttt{evaluate.\allowbreak load(\allowbreak "tên\_\allowbreak metric")} để tải metric, sau đó dùng \texttt{.add\_batch()} và \texttt{.compute()} để tính toán.
    \item \textbf{Hỗ trợ phân tán:} Tự động tổng hợp các dự đoán và nhãn từ nhiều GPU khi dùng cùng \texttt{accelerate}.
\end{itemize}
\begin{example}{Dùng \texttt{evaluate} để tính F1-score}{ex:hf_evaluate}
    \begin{minted}{python}
    import evaluate

    # Tải metric F1
    f1_metric = evaluate.load("f1")

    # Giả sử có các dự đoán và nhãn
    predictions = [0, 1, 0, 1, 1]
    references = [0, 0, 0, 1, 1]

    # Tính toán
    results = f1_metric.compute(predictions=predictions, references=references)
    print(results)
    # Output: {'f1': 0.8}
    \end{minted}
\end{example}

Bốn thư viện này hợp lại thành một quy trình làm việc đã được tiêu chuẩn hóa, nhờ đó phần lớn công sức dành cho việc xây dựng mô hình thay vì cho các chi tiết kỹ thuật ở bên dưới.
