\section{Kỹ thuật đánh giá thực tế}
\label{sec:practical_evaluation}

Theo dõi các metric đánh giá trong suốt quá trình huấn luyện cho biết mô hình đang hoạt động tốt đến đâu, và giúp phát hiện sớm các vấn đề như quá khớp (overfitting) hoặc dưới khớp (underfitting).

\texttt{Trainer} của thư viện \texttt{transformers} hỗ trợ đánh giá định kỳ trên tập validation. Để dùng được, bạn cung cấp cho nó một hàm tùy chỉnh, thường đặt tên là \texttt{compute\_metrics}.

\subsection{Hàm \texttt{compute\_metrics}}
\label{ssec:compute_metrics_function}

\begin{itemize}
    \item \textbf{Mục đích:} \texttt{compute\_metrics} là một hàm Python mà bạn tự định nghĩa. \texttt{Trainer} gọi hàm này sau mỗi epoch, hoặc sau một số bước nhất định, trong quá trình huấn luyện.
    \item \textbf{Đầu vào:} Một đối tượng \texttt{EvalPrediction}, là một tuple chứa hai mảng NumPy: \texttt{predictions} (các logits đầu ra từ mô hình) và \texttt{label\_ids} (các nhãn thật từ bộ dữ liệu).
    \item \textbf{Đầu ra:} Một dictionary, trong đó key là tên của metric (ví dụ \texttt{"f1"}) và value là giá trị của metric đó.
\end{itemize}

\paragraph{Quy trình bên trong một hàm \texttt{compute\_metrics}}
Một hàm \texttt{compute\_metrics} điển hình thực hiện các bước sau:
\begin{enumerate}
    \item \textbf{Tải các metric cần thiết} từ thư viện \texttt{evaluate}.
    \item \textbf{Tiền xử lý đầu ra của mô hình:} \texttt{predictions} thường là các logits, tức các số thực thô. Cần chuyển chúng thành dự đoán cuối cùng, ví dụ bằng cách lấy \texttt{argmax} trên chiều cuối cùng, để so sánh được với các nhãn.
    \item \textbf{Tính toán các metric:} Dùng các đối tượng metric đã tải, truyền vào các dự đoán đã xử lý và các nhãn thật.
    \item \textbf{Trả về kết quả:} Một dictionary chứa các điểm số đã tính được.
\end{enumerate}

\begin{example}{Một hàm \texttt{compute\_metrics} cho bài toán phân loại chuỗi}{ex:compute_metrics_classification}
    Đây là một ví dụ hoàn chỉnh cho một bài toán phân loại nhị phân, sử dụng F1, Precision và Recall.
    \begin{minted}{python}
    import numpy as np
    import evaluate

    # Tải trước các metric để không phải tải lại mỗi lần gọi hàm
    f1_metric = evaluate.load("f1")
    precision_metric = evaluate.load("precision")
    recall_metric = evaluate.load("recall")

    def compute_metrics(eval_preds):
        # eval_preds là một tuple (predictions, label_ids)
        logits, labels = eval_preds
        
        # 1. Chuyển đổi logits thành dự đoán cuối cùng
        # Lấy chỉ số của logit lớn nhất trên chiều cuối cùng (-1)
        predictions = np.argmax(logits, axis=-1)
        
        # 2. Tính toán từng metric
        f1 = f1_metric.compute(predictions=predictions, references=labels)["f1"]
        precision = precision_metric.compute(predictions=predictions, references=labels)["precision"]
        recall = recall_metric.compute(predictions=predictions, references=labels)["recall"]
        
        # 3. Trả về một dictionary
        return {
            "f1": f1,
            "precision": precision,
            "recall": recall,
        }

    # Sau đó, hàm này sẽ được truyền vào đối tượng TrainingArguments:
    # training_args = TrainingArguments(..., eval_strategy="epoch")
    # trainer = Trainer(
    #     ...,
    #     args=training_args,
    #     compute_metrics=compute_metrics,
    # )
    # trainer.train()
    \end{minted}
\end{example}

\subsection{Đánh giá các tác vụ phức tạp hơn}
\label{ssec:complex_task_evaluation}

\subsubsection{Gán nhãn chuỗi (NER) với \texttt{seqeval}}
Với các tác vụ như nhận dạng thực thể tên (NER), đánh giá không phải là so sánh từng nhãn một. Điều cần biết là mô hình có nhận dạng đúng \textbf{toàn bộ các thực thể}, cả ranh giới và loại, hay không. Ví dụ, dự đoán \texttt{[B-PER, I-PER]} cho “Hồ Chí Minh” là đúng, còn dự đoán \texttt{[B-PER, B-LOC]} là sai hoàn toàn, mặc dù đúng được 1/2 nhãn.

\texttt{seqeval} là một thư viện Python chuyên để đánh giá các tác vụ gán nhãn chuỗi, cũng được tích hợp trong \texttt{evaluate}. Nó tính Precision, Recall và F1-score ở cấp độ thực thể (entity-level) theo các định dạng chuẩn như IOB2.

\begin{example}{Hàm \texttt{compute\_metrics} cho NER}{ex:compute_metrics_ner}
    \begin{minted}{python}
    import numpy as np
    import evaluate

    # Tải metric seqeval
    seqeval_metric = evaluate.load("seqeval")

    # Giả sử chúng ta có mapping từ ID sang nhãn
    label_names = ['O', 'B-PER', 'I-PER', 'B-LOC', 'I-LOC']

    def compute_metrics_ner(eval_preds):
        logits, labels = eval_preds
        predictions = np.argmax(logits, axis=-1)

        # Chuyển đổi ID trở lại thành nhãn chuỗi
        # Bỏ qua các nhãn padding (thường có ID là -100)
        true_labels = [
            [label_names[l] for l in label if l != -100]
            for label in labels
        ]
        true_predictions = [
            [label_names[p] for p, l in zip(prediction, label) if l != -100]
            for prediction, label in zip(predictions, labels)
        ]
        
        # Tính toán metric
        results = seqeval_metric.compute(predictions=true_predictions, references=true_labels)
        
        # Trả về các metric chính
        return {
            "precision": results["overall_precision"],
            "recall": results["overall_recall"],
            "f1": results["overall_f1"],
            "accuracy": results["overall_accuracy"],
        }
    \end{minted}
\end{example}

\subsubsection{Sinh văn bản (tóm tắt, dịch máy) với ROUGE và BLEU}
Các mô hình sinh văn bản (Decoder-Only, Encoder-Decoder) tạo ra các chuỗi có độ dài thay đổi, nên việc đánh giá phải so sánh các chuỗi này với các chuỗi tham khảo. Vấn đề là \texttt{Trainer} thường không \emph{sinh} gì cả: vòng lặp đánh giá của nó chỉ chạy một lượt truyền thẳng và trả về logits, nên không có chuỗi văn bản nào để decode và đem so với chuỗi tham khảo.

Cách giải quyết là dùng \texttt{Seq2Seq\allowbreak Trainer} cùng với \texttt{Seq2Seq\allowbreak Training\allowbreak Arguments} -- \texttt{predict\_\allowbreak with\_\allowbreak generate} là tham số của lớp \texttt{Seq2Seq\allowbreak Training\allowbreak Arguments}, không có trong \texttt{Training\allowbreak Arguments} thường. Khi đặt \texttt{eval\_strategy} cùng với \texttt{predict\_\allowbreak with\_\allowbreak generate=True}, \texttt{Seq2Seq\allowbreak Trainer} tự động:
\begin{enumerate}
    \item Chạy quá trình sinh văn bản (\texttt{.generate()}) trên tập validation.
    \item Thu thập (gather) các kết quả từ tất cả các thiết bị.
\end{enumerate}
Phần còn lại, decode và tính metric, nằm trong hàm \texttt{compute\_metrics}.

\begin{example}{Hàm \texttt{compute\_metrics} cho Tóm tắt (sử dụng ROUGE)}{ex:compute_metrics_summarization}
    \begin{minted}{python}
    import numpy as np
    import evaluate
    from transformers import AutoTokenizer # Cần tokenizer để decode

    # Giả sử tokenizer đã được định nghĩa ở ngoài
    tokenizer = AutoTokenizer.from_pretrained("t5-small")
    rouge_metric = evaluate.load("rouge")

    def compute_metrics_summarization(eval_preds):
        predictions, labels = eval_preds

        # Decode các token ID thành văn bản
        # Bỏ qua các token padding
        decoded_preds = tokenizer.batch_decode(predictions, skip_special_tokens=True)
        
        # Thay thế các token padding (-100) trong nhãn bằng pad_token_id
        # để chúng cũng có thể được decode đúng cách
        labels = np.where(labels != -100, labels, tokenizer.pad_token_id)
        decoded_labels = tokenizer.batch_decode(labels, skip_special_tokens=True)

        # Tính ROUGE score
        result = rouge_metric.compute(predictions=decoded_preds, references=decoded_labels, use_stemmer=True)

        # Trích xuất các điểm số chính
        prediction_lens = [np.count_nonzero(pred != tokenizer.pad_token_id) for pred in predictions]
        result["gen_len"] = np.mean(prediction_lens)
        
        return {k: round(v, 4) for k, v in result.items()}
    \end{minted}
\end{example}

Một hàm \texttt{compute\_metrics} viết đúng và phù hợp với tác vụ là điều kiện để quy trình huấn luyện và đánh giá đáng tin cậy.
